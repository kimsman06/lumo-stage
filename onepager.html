🛠️ 시스템 아키텍처 스택

기술 구성 요약

  • React 18 + Vite + R3F 조합으로 WebGL 뷰포트를 구축하고, Drei 헬퍼로 OrbitControls·TransformControls를 제공합니다.
  • Zustand + Immer 스토어가 `sceneData`와 UI 상태를 단일 소스로 관리하며, Snapshot 미들웨어로 Undo/Redo를 처리합니다.
  • shadcn/ui·Tailwind UI 시스템을 Hero·Dashboard·Editor 전반에 적용해 일관된 토큰과 접근성 규칙을 유지합니다.
  • 커스텀 Light/Diffuser 컴포넌트와 GLTF 자산 로더가 Three.js 장면에 즉시 반영되고, orbit/camera 동기화로 동일한 시점을 복원합니다.
  • express-session 기반 인증과 프로젝트·씬 REST API가 동일 도메인에서 세션 쿠키를 발급해 보안 컨텍스트를 유지합니다.

아키텍처 개괄

  • React UI → Zustand → Three.js 렌더러 흐름으로 사용자의 편집 이벤트가 실시간 장면 업데이트로 이어집니다.
  • REST API 클라이언트가 세션 쿠키를 포함해 Express 컨트롤러와 통신하며, 서비스 계층이 장면 데이터를 정규화합니다.
  • Express 서비스는 MongoDB·에셋 스토리지 계층을 추상화하고, HDRI·GLTF 자산과 프로젝트 메타데이터를 일관되게 제공합니다.
  • Mermaid 다이어그램은 이러한 경로를 모듈 단위로 표현해 어느 계층에서 상태/자원이 이동하는지 한눈에 파악할 수 있게 합니다.

🧭 LumoStage 핵심 기능 안내

프로젝트 허브, 실시간 라이팅 에디터, 공유 뷰어를 중심으로 LumoStage에서 바로 활용할 수 있는 대표 기능을 소개합니다.

우선순위 추후 개발 예정 기능 주요 내용 예정 단계
P0 OrbitControl·카메라 동기화 `orbitControlState` 저장과 View↔Camera 전환, 온보딩 QA로 첫 프로젝트 저장까지 10분 이내 경험을 보장합니다. Phase 4 · 핵심 UX 개선
P1 HDRI & 오브젝트 확장 `BackgroundControl`·`ObjectsControl`로 HDRI 업로드, Ground Plane, GLTF 배치를 제공해 촬영 환경을 재현합니다. Phase 5 · 씬 구성 확장
P2 전문가 UI & 스케일 도구 Outliner·Properties·Toolbar 리디자인과 R(Scale) 모드, 패널 토글, Undo/Redo로 전문가 워크플로우를 보강합니다. Phase 6 · 전문가 UI
P3 Google Nano Banana 프리비주얼 PrevisualizationPanel에서 씬 캡처와 프롬프트를 제출하면 Bull Queue가 이미지를 생성해 프로젝트 히스토리에 저장합니다. Phase 7 · AI 기능

🗂️ 핵심 데이터 모델

협업 중심 저장 구조를 위해 프로젝트, 씬, 라이트, 스냅샷 네 가지 컬렉션을 핵심으로 구성했습니다.

🗃️ projects — ownerId, 참가자 배열, 최신 씬 참조, 공유 토큰 설정.
🖼️ scenes — projectId, 카메라 상태, 환경 옵션, 포함된 lightIds, 버전 번호.
💡 lights — sceneId, 라이트 유형(spot · rect · area · point), 변환, 색상, 강도, 섀도 설정.
🕒 snapshots — sceneId, 저장자, 전체 payload, 자동 저장 여부, 레이블.

🔗 API 구조 요약

Express 기반 REST API는 express-session + MongoDB 스토어로 세션을 관리하고 Zod 스키마로 요청을 검증하며, WebSocket 확장을 대비한 모듈형 컨트롤러/서비스 계층을 유지합니다.

🔐 Authentication — GET /auth/csrf-token, POST /auth/register, POST /auth/login, POST /auth/logout.
📁 Projects — GET /projects, POST /projects, GET /projects/:id/scenes.
🎬 Scenes — POST /scenes, PATCH /scenes/:id, POST /snapshots.
💡 Lighting & Assets — PATCH /lights/:id, POST /lights/bulk, POST /assets/upload.
🤝 Sharing — POST /share-tokens, GET /share/:token, POST /feedback.

🌟 LumoStage 핵심 요약

브라우저 한 탭에서 조명 프리비주얼과 협업을 연결하는 LumoStage는 MERN 스택과 Three.js를 결합해 실시간 3D 씬 편집, 세션 기반 협업, 향후 AI 프리비주얼까지 확장 가능한 프로덕션 허브를 지향합니다.

학생·독립 제작자·크리에이터를 겨냥한 웹 기반 조명 스튜디오로, 설치형 고가 툴 대비 가벼운 온보딩과 프로젝트 중심 협업 경험을 제공합니다.

핵심 역량

React 18 + Zustand로 관리되는 실시간 3D 에디터, express-session 인증, HDRI·GLTF 확장을 염두에 둔 REST 아키텍처가 기반 워크플로우를 구성합니다.
