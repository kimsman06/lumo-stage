프로젝트 개요

문제점

  • 실제 촬영 현장에서 조명 설치와 테스트에 많은 시간과 비용 소모
  • Cinema 4D, Blender 같은 전문 3D 소프트웨어는 고가이고 학습 곡선이 가파름
  • 영상 제작 팀 간 조명 구도 커뮤니케이션의 어려움

해결책: LumoStage

  • 웹 브라우저에서 바로 사용 (설치 불필요)
  • 조명과 카메라 구도를 실시간 시뮬레이션
  • 초보자부터 전문가까지 접근성 높은 도구

관계 요약

  • USER → PROJECT: 사용자가 다수의 프로젝트를 소유하며 접근 제어는 ObjectId 기반.
  • PROJECT → ASSET / PREVIS: 씬 데이터 저장소와 AI 파이프라인 산출물이 동일 프로젝트에서 파생.
  • USER → ASSET / PREVIS: 개인별 사용량 추적을 위한 직접 소유 관계를 유지해 비용 및 AI 크레딧 계산 가능.

핵심 속성

USER

username / email: 고유 식별과 소셜 로그인 매핑 기준.

aiApiKey: 사용자 개인의 Gemini 키를 암호화해 저장.

aiUsageStats: 월간 호출 횟수/비용을 JSON 메타로 누적.

PROJECT

sceneData: Three.js 편집 상태를 그대로 직렬화한 JSON.

thumbnail: 프리뷰 이미지 URL, 리스트 UX 향상.

createdAt: 프로젝트 타임라인/정렬 기준.

ASSET

fileKey / fileUrl: R2 스토리지 접근 키와 CDN URL.

mimeType: 렌더러/다운로드 시 안전한 Content-Type 결정.

fileSize: 업로드 제한·요금 측정을 위한 기준.

PREVIS

prompt: AI 호출에 사용된 자연어 프롬프트 기록.

sceneRenderUrl: 편집 장면을 캡처한 참고 이미지.

generatedImageUrl: Gemini 결과물을 저장한 URL.

데이터 구성

  • schemaVersion / aspectRatio: 저장 포맷 버전을 명시해 역호환.
  • mannequins: 위치·회전을 배열로 유지해 GLTF 리깅과 호환.

카메라 & Orbit

  • orbitControlState는 사용자 컨트롤 상태를 저장해 복원.
  • 두 상태를 분리해 UI 조작과 렌더 카메라가 엉키지 않음.

환경 설정

  • backgroundSettings는 HDRI/ground 옵션 묶음.
  • 최소 필드만 포함해 API payload를 가볍게 유지.
  • 추가 컴포넌트 도입 시에도 동일 구조로 확장 가능.

핵심 코드: Zustand 상태 관리 (실제 구현)

// client/src/store/editorStore.js - Zustand 전역 상태 관리
// 모든 3D Scene 상태를 중앙에서 관리하여 컴포넌트 간 데이터 공유

const useStore = create((set, get) => ({
  // ===== 상태 정의 =====
  lights: createDefaultLights(),
  mannequins: [{ id: nanoid(), position: [0, -1.5, 0], pose: createInitialPose() }],
  cameraState: { position: [0, 2, 8], target: [0, 2, 0], focalLength: 50 },
  orbitControlState: { cameraPosition: [0, 2, 8], target: [0, 2, 0], zoom: 1 },
  backgroundSettings: sanitizeBackgroundSettings(),

  // ===== 액션: 조명 관리 =====
  addLight: (type = 'point') => {
    set((state) => {
      const lightCount = state.lights.length + 1;
      const commonProps = {
        id: nanoid(),
        visible: true,
        position: [0, 3, 0],
        color: '#ffffff',
        intensity: 10,
        castShadow: true
      };
      let newLight;
      switch (type) {
        case 'spot':
          newLight = {
            ...commonProps,
            type: 'spot',
            name: `Spot Light ${lightCount}`,
            angle: Math.PI / 4,
            penumbra: 0.5,
            targetPosition: [0, 0, 0]
          };
          break;
      }
      return { lights: [...state.lights, newLight] };
    });
    setTimeout(() => get().saveHistory(), 0);
  },

  updateLight: (id, property, value) =>
    set((state) => ({
      lights: state.lights.map((light) =>
        light.id === id ? { ...light, [property]: value } : light
      )
    })),

  deleteLight: (id) => {
    set((state) => ({
      lights: state.lights.filter((light) => light.id !== id)
    }));
    setTimeout(() => get().saveHistory(), 0);
  },

  // ===== Scene 데이터 직렬화 (저장용) =====
  getSceneData: () => {
    const state = get();
    return {
      mannequins: state.mannequins.map(({ poseInitialized, ...rest }) => ({ ...rest })),
      lights: state.lights,
      cameraState: state.cameraState,
      orbitControlState: state.orbitControlState,
      aspectRatio: state.aspectRatio,
      backgroundSettings: state.backgroundSettings
    };
  },

  // ===== Scene 데이터 로드 (API에서 받은 데이터로 초기화) =====
  loadSceneData: (sceneData) => {
    if (!sceneData) return;
    set((state) => {
      const updates = {};
      if (sceneData.mannequins) {
        updates.mannequins = sceneData.mannequins.map((m, i) => sanitizeMannequin(m, i));
      }
      if (sceneData.lights) {
        updates.lights = sceneData.lights.map((l, i) => sanitizeLight(l, i)).filter(Boolean);
      }
      if (sceneData.cameraState) updates.cameraState = sceneData.cameraState;
      if (sceneData.orbitControlState) updates.orbitControlState = sceneData.orbitControlState;
      updates.backgroundSettings = sanitizeBackgroundSettings(sceneData.backgroundSettings);
      return updates;
    });
    setTimeout(() => get().saveHistory(), 0);
  }
}));

export default useStore;

상태 구조

  • lights / mannequins: 시각 요소를 배열로 관리해 Three.js 객체와 싱크.
  • cameraState / orbitControlState: 카메라와 OrbitControls를 분리 저장해 동기화 루프 방지.
  • backgroundSettings: HDRIㆍground 옵션을 묶어 Scene 저장/로드 시 누락 방지.

액션 흐름

  • addLight는 타입별 공통 속성을 생성하고 history에 비동기 저장.
  • updateLight / deleteLight는 불변 업데이트로 diff 추적이 쉬움.
  • getSceneData는 API 전송용 순수 객체로 직렬화.

데이터 정화

  • loadSceneData에서 sanitize 함수로 구버전과 호환.
  • setTimeout(...saveHistory)는 UI 업데이트 이후에 기록해 스로틀링.
  • 모든 액션은 동기적으로 상태를 바꿔 Zustand 철학을 유지.

핵심 코드: Scene 데이터 정규화 (실제 구현) 

// server/services/scene.service.js - Scene 데이터 정규화
// API에서 받은 데이터를 검증하여 프로젝트 간 상태 오염 방지

const DEFAULT_SCHEMA_VERSION = 2;
const DEFAULT_ASPECT_RATIO = "16:9";
const DEFAULT_ORBIT_CONTROL_STATE = {
  cameraPosition: [0, 2, 8],
  target: [0, 2, 0],
  zoom: 1
};

const ensureVector3 = (value, fallback, dirtyRef) => {
  if (
    !Array.isArray(value) ||
    value.length !== 3 ||
    value.some((c) => typeof c !== 'number')
  ) {
    dirtyRef.dirty = true;
    return fallback;
  }
  return value;
};

const normalizeLight = (light, dirtyRef) => {
  if (!light) {
    dirtyRef.dirty = true;
    return { id: `light-${Date.now()}`, type: 'spot' };
  }
  const normalized = { ...light };
  if (!normalized.id) {
    normalized.id = `light-${Date.now()}-${Math.random().toString(36).slice(2, 8)}`;
    dirtyRef.dirty = true;
  }
  return normalized;
};

const normalizeOrbitControlState = (orbitControlState, dirtyRef) => {
  if (!orbitControlState) {
    dirtyRef.dirty = true;
    return { ...DEFAULT_ORBIT_CONTROL_STATE };
  }
  const normalized = { ...orbitControlState };
  normalized.cameraPosition = ensureVector3(
    normalized.cameraPosition,
    DEFAULT_ORBIT_CONTROL_STATE.cameraPosition,
    dirtyRef
  );
  normalized.target = ensureVector3(
    normalized.target,
    DEFAULT_ORBIT_CONTROL_STATE.target,
    dirtyRef
  );
  return normalized;
};

// 메인 정규화 함수
const normalizeSceneData = (sceneData = {}) => {
  const dirtyRef = { dirty: false };

  if (!sceneData || typeof sceneData !== 'object') {
    dirtyRef.dirty = true;
    sceneData = {};
  }

  const normalized = { ...sceneData };

  // 스키마 버전 확인
  if (normalized.schemaVersion !== DEFAULT_SCHEMA_VERSION) {
    normalized.schemaVersion = DEFAULT_SCHEMA_VERSION;
    dirtyRef.dirty = true;
  }

  // Aspect Ratio 정규화
  if (!normalized.aspectRatio) {
    normalized.aspectRatio = DEFAULT_ASPECT_RATIO;
    dirtyRef.dirty = true;
  }

  // OrbitControls 상태 정규화
  normalized.orbitControlState = normalizeOrbitControlState(
    normalized.orbitControlState,
    dirtyRef
  );

  // Lights 배열 정규화
  if (!Array.isArray(normalized.lights)) {
    normalized.lights = [];
    dirtyRef.dirty = true;
  } else {
    normalized.lights = normalized.lights.map((light) => normalizeLight(light, dirtyRef));
  }

  // Mannequins 배열 정규화
  if (!Array.isArray(normalized.mannequins)) {
    normalized.mannequins = [];
    dirtyRef.dirty = true;
  }

  return {
    data: normalized,
    dirty: dirtyRef.dirty
  };
};

const applySceneDefaults = (projectDoc) => {
  const { data, dirty } = normalizeSceneData(projectDoc.sceneData);
  if (dirty) {
    projectDoc.sceneData = data;
    projectDoc.markModified('sceneData');
  }
};

module.exports = {
  normalizeSceneData,
  applySceneDefaults
};

정규화 목적

  • S3/R2에서 불완전한 Scene을 로드해도 기본값으로 복구.
  • dirtyRef로 보정 여부를 추적해 API 응답에 안내 가능.

검증 포인트

  • ensureVector3: 좌표 배열 길이/타입을 엄격히 검사.
  • normalizeLight: ID 없음 → 타임스탬프 기반 ID 부여.
  • normalizeOrbitControlState: 카메라 좌표를 Vector3 보정.

적용 흐름

  • API에서 Scene 수신 → 정규화 후 MongoDB 저장.
  • dirty 상태면 프론트로 플래그 전달해 사용자에게 경고.
  • Schema version 업데이트 시에도 최소한의 필드로 유지.

Prompt 빌더 (mergePrompt) 

const SYSTEM_INSTRUCTIONS = [
  "You are rendering photorealistic stage visuals for LumoStage.",
  "Use the uploaded render strictly as the camera guide."
].join(" ");

const DEFAULT_NEGATIVE = "plastic skin, mannequin, distorted lens";

const mergePrompt = (prompt, negativePrompt, sceneSnapshot) => {
  let instructions = SYSTEM_INSTRUCTIONS;

  if (sceneSnapshot?.environment?.hdriName) {
    instructions += `\nUse the ${sceneSnapshot.environment.hdriName} environment map cues.`;
  }
  if (sceneSnapshot?.environment?.color) {
    instructions += `\nAmbient color should match ${sceneSnapshot.environment.color}.`;
  }

  const combinedPrompt = `${instructions}\n\n` + prompt;
  const negatives = [DEFAULT_NEGATIVE];
  if (negativePrompt?.trim()) {
    negatives.push(negativePrompt.trim());
  }

  return `${combinedPrompt}\n\nAvoid: ` + negatives.join(", ");
};

Prompt → Gemini 요청 (buildContents & request) 

const buildContents = ({ prompt, imageBuffer, mimeType }) => {
  const parts = [{ text: prompt }];
  if (imageBuffer) {
    parts.push({
      inlineData: {
        data: imageBuffer.toString("base64"),
        mimeType: mimeType || "image/png"
      }
    });
  }
  return [{ role: "user", parts }];
};

const requestPrompt = mergePrompt(prompt, negativePrompt, sceneSnapshot);
const request = {
  model: model || DEFAULT_GEMINI_IMAGE_MODEL,
  contents: buildContents({ prompt: requestPrompt, imageBuffer, mimeType }),
  config: { responseModalities: ["TEXT", "IMAGE"] }
};

const imageConfig = buildImageConfig({ aspectRatio, imageSize });
if (imageConfig) {
  request.config.imageConfig = imageConfig;
}

const response = await ai.models.generateContent(request);
const imagePart = extractImagePart(response);

Gemini 프롬프트 가이드

  • 카메라: `sceneSnapshot.cameraState`를 그대로 사용해 구도를 고정.
  • 조명: `environment.hdriName`과 ambient color를 prompt에 명시.
  • 피사체: mannequin 언급 금지, realistic performer 지시어 추가.
  • 안전: distorted lens, stretched body 등 금지 키워드를 negative prompt에 삽입.
  • 출력: `responseModalities`를 TEXT+IMAGE로 지정하고 `buildImageConfig(aspectRatio)` 적용.
  • 메타데이터: `extractImagePart()` 결과의 model/imageConfig를 Scene history와 동기화.
