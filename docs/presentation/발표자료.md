## 슬라이드 2: 프로젝트 개요

### 문제점
- 실제 촬영 현장에서 조명 설치와 테스트에 많은 시간과 비용 소모
- Cinema 4D, Blender 같은 전문 3D 소프트웨어는 고가이고 학습 곡선이 가파름
- 영상 제작 팀 간 조명 구도 커뮤니케이션의 어려움

### 해결책: LumoStage
- **웹 브라우저에서 바로 사용**하는 3D 조명 시뮬레이터
- 실제 촬영 전 조명과 카메라 구도를 **실시간으로 시뮬레이션**
- 영화/영상 전공 학생, 독립 영화 제작자, 유튜버를 위한 **접근성 높은 도구**

## 슬라이드 3: 기술 스택 및 아키텍처

### Frontend
- **React + Vite**: 빠른 개발 환경
- **Three.js + React-Three-Fiber**: 실시간 3D 렌더링
- **Zustand**: 단방향 데이터 흐름 기반 상태 관리
- **Tailwind CSS + shadcn/ui**: 모던 UI 시스템

### Backend
- **Node.js + Express**: REST API 서버 (MVCS 패턴)
- **MongoDB**: 프로젝트/사용자 데이터 저장
- **Cloudflare R2**: HDRI/GLB 파일 스토리지 (S3 호환)
- **Session + Passport.js**: Google/Naver 소셜 로그인

### AI 통합
- **Gemini 2.5 Flash Image**: Scene-to-Photo 변환
- **Bull Queue + Redis**: 비동기 이미지 생성 처리

### 아키텍처 특징
- **단방향 데이터 흐름**: UI → Zustand Store → 3D Scene
- **MVCS 패턴**: Routes → Controllers → Services → Models

## 슬라이드 9: 어려웠던 점 (1/2)

### 1. OrbitControls와 Camera 상태 동기화
**문제**:
- Three.js OrbitControls는 자체 카메라를 조작
- 사용자가 탐색한 시점을 "카메라 뷰"로 설정하고 싶음
- 프로젝트 저장/로드 시 OrbitControls 위치도 복원해야 함

**해결**:
```javascript
// Phase 4에서 Cinema 4D 스타일 동기화 구현
setOrbitToCameraView: () => {
  const { cameraState, orbitControlsRef } = get();
  if (orbitControlsRef) {
    orbitControlsRef.object.position.set(...cameraState.position);
    orbitControlsRef.target.set(...cameraState.target);
  }
}

setCameraViewToOrbit: () => {
  const { orbitControlsRef } = get();
  if (orbitControlsRef) {
    const pos = orbitControlsRef.object.position;
    const target = orbitControlsRef.target;
    set({
      cameraState: {
        position: [pos.x, pos.y, pos.z],
        target: [target.x, target.y, target.z]
      }
    });
  }
}
```

**결과**:
- "Set Camera to View", "View from Camera" 버튼으로 양방향 전환
- OrbitControls 위치도 프로젝트에 저장/복원 (100% 정확도)

**해결**:

- Asset 모델로 파일 메타데이터 관리
- Cascade 삭제: 프로젝트 삭제 시 연결된 에셋 자동 삭제

```javascript
// storage.service.js
async uploadFile(buffer, key, mimeType) {
  const command = new PutObjectCommand({
    Bucket: process.env.R2_BUCKET_NAME,
    Key: key,
    Body: buffer,
    ContentType: mimeType
  });
  await s3Client.send(command);
  return `${process.env.R2_PUBLIC_URL}/${key}`;
}
```

**결과**:
- HDRI 업로드 성공률 99% 이상
- 업로드 시간 10초 이내 (50MB 기준)

**난이도**: ⭐⭐⭐⭐

**도전 과제**:
- 사용자가 직접 Gemini API 키 입력
- API 키를 안전하게 저장 (DB 해킹 시 유출 방지)
- Scene 이미지를 Gemini에 전송하여 실사 변환

**구현**:
```javascript
// encryption.js - AES-256-GCM 암호화
const algorithm = 'aes-256-gcm';
const key = Buffer.from(process.env.ENCRYPTION_KEY, 'hex');

function encrypt(text) {
  const iv = crypto.randomBytes(16);
  const cipher = crypto.createCipheriv(algorithm, key, iv);
  const encrypted = Buffer.concat([cipher.update(text, 'utf8'), cipher.final()]);
  const authTag = cipher.getAuthTag();

  return {
    iv: iv.toString('hex'),
    encryptedData: encrypted.toString('hex'),
    authTag: authTag.toString('hex')
  };
}
```

**보안 고려사항**:
- 환경변수로 암호화 키 관리
- IV(Initialization Vector) 매번 랜덤 생성
- authTag로 무결성 검증

**결과**: DB 해킹 시에도 API 키 복호화 불가능
